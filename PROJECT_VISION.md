# PROJECT SPECTER 3D — SPEC v3 (this file overrides all older docs)

## 0. READ FIRST (every session)
1. LOOKS ARE THE GAME. Flat gray boxes, untextured primitives, empty rooms =
   FAILED task. Believable dark horror atmosphere is a core requirement.
2. ZERO external assets. Every mesh, texture, material, sound, animation and
   UI graphic is generated by code (Section 4).
3. Every iteration: implement -> commit/push -> test per aider_continue.md
   (remote godot-playtester + screenshots) -> judge screenshots -> fix.
4. Never restart or redesign the project. Evolve the existing code.
5. When unsure between options, pick the one that makes the game look more
   like a real place and feel scarier.

## 1. GAME
Asymmetric PvP first-person horror. Godot 4.x, GDScript only.
- 3-4 Investigators vs 1-2 Entity players in a procedurally generated
  building (deterministic from a seed).
- Investigators: explore, collect evidence, identify the entity type, finish
  objectives, unlock extraction, survive a loud countdown, escape.
- Entity: invisible; manipulates doors/lights/objects/sounds, builds fear,
  hunts isolated players, blocks extraction.
- Crossplay Windows <-> Android, one codebase, Godot high-level multiplayer
  (ENet, host/join). No platform branches in gameplay code.
- First-person only, camera at 1.65 m eye height. Never top-down.

## 5. VISUAL STANDARD (the most important section)

### 5.1 Global atmosphere (do this once, early)
WorldEnvironment + ProceduralSkyMaterial (night): ambient #10141c low energy;
tonemap ACES, exposure ~0.9; subtle glow; fog #0b0e14 (volumetric desktop
only); SSAO desktop only; optional faint moonlight DirectionalLight3D through
windows. This alone turns "polygon space" into a horror building.

### 5.2 Materials — nothing visible keeps a default material
Every visible surface gets a StandardMaterial3D with:
- procedural albedo texture: grime/concrete/metal -> NoiseTexture2D
  (FastNoiseLite, 256 px); planks/wallpaper/tiles -> GradientTexture2D with
  repeat; posters/signs/screens/faces -> ImageTexture from a pixel loop;
- albedo_color from the palette (5.10) multiplied on top;
- roughness 0.6-0.95, varied per surface.
Use ONE static MaterialFactory (5.11) with caching. Reuse materials.

|----------------|-----------------------|
| eye height     | 1.65 m                |
| ceiling        | 2.8 m                 |
| door           | 2.05 H x 0.95 W m     |

Everything rests on the floor with collision. Nothing floats.

### 5.4 Build order
MAP -> ROOM -> FURNITURE -> PROPS -> CHARACTER -> DETAILS.
A room with only floor and walls is INCOMPLETE.

### 5.5 Room kits (a stranger must recognize the room from one screenshot)
- Kitchen: counter run, sink, fridge, table+chairs, hanging lamp.
- Bedroom: bed, wardrobe, nightstand+lamp, rug, window.
- Bathroom: tub, toilet, sink, metallic mirror.
- Hallway: door frames, ceiling lamps, pictures, baseboards.
- Library/office: bookshelves (books = thin colored boxes), desk, chair.
- Storage: crates, metal shelves, clutter.
- Electrical: breaker panel, generator, cable cylinders.
- Extraction: marked gate, device, emissive sign.

### 5.6 Cheap realism details (add to every room)
Baseboards; door frames with trim; window frames + translucent reflective
glass; a lamp fixture mesh above every OmniLight (#ffd9a0, energy ~1.2, some
off or flickering); 1-3 pictures (frame box + ImageTexture); GPUParticles3D
dust near lamps; doors swing on a hinge pivot with a creak sound.

### 5.7 Characters (required, not optional)
- Humanoid from primitives: head (box/sphere) with a generated face texture
  (5.11); torso; upper+lower arm and leg segments, each hung from a Node3D
  pivot whose mesh child is offset half its length down (rotating the pivot
  swings the limb).
- Procedural animation in code: walk = sin() limb swing + body bob; idle =
  subtle breathing; vary skin/cloth colors per player.
- Faceless mannequins are a FAILURE. Faces are code-made ImageTextures.
- Local player viewmodel: arms + active tool attached to the camera, with
  sway/bob; camera lowers when crouching.
- Entity: normally NO mesh at all (fully invisible). Manifestation = dark
  translucent humanoid, emissive pale eyes, distortion shader.

### 5.8 Equipment (viewmodel + behavior + sound)
flashlight = mesh + SpotLight (~25 deg, 12 m range) + battery drain.
EMF reader = small box + screen texture updated live with readings + beeps.
Thermometer, motion sensor, spirit box = same pattern. Entity powers get a
selection HUD.

### 5.9 UI bar
One code-generated Theme for ALL screens: bg #0d0f14, accent #c9b458, styled
buttons with hover/press states. Flow: splash (animated fog/particles +
title) -> menu -> host/join -> lobby (names, roles, ready) -> match ->
results (win/lose, evidence, objectives). HUD: fear meter, objective tracker,
current tool, interaction prompt, extraction status. Pause is local UI only,
never pauses the network. Settings persist to disk. Must read well on a phone.

### 5.11 Copy these exact patterns into your generators
```gdscript
# scripts/procedural/material_factory.gd
class_name MaterialFactory

static func grime(base: Color, rough := 0.9, freq := 0.05) -> StandardMaterial3D:
	var noise := FastNoiseLite.new()
	noise.frequency = freq
	var tex := NoiseTexture2D.new()
	tex.noise = noise
	tex.width = 256
	tex.height = 256
	var m := StandardMaterial3D.new()
	m.albedo_color = base   # albedo_color multiplies albedo_texture
	m.albedo_texture = tex
	m.roughness = rough
	return m

static func planks(base := Color("6b5237")) -> StandardMaterial3D:
	var grad := Gradient.new()
	grad.offsets = PackedFloat32Array([0.0, 0.45, 0.5, 1.0])
	grad.colors = PackedColorArray([base, base.darkened(0.2), base.darkened(0.4), base])
	var tex := GradientTexture2D.new()
	tex.gradient = grad
	tex.width = 64
	tex.height = 512
	tex.fill = GradientTexture2D.FILL_LINEAR
	tex.fill_from = Vector2(0, 0)
	tex.fill_to = Vector2(0, 1)
	tex.repeat = GradientTexture2D.REPEAT_ENABLED
	var m := StandardMaterial3D.new()
	m.albedo_texture = tex
	m.roughness = 0.85
	return m

static func face_texture(skin := Color("c8a284")) -> ImageTexture:
	var img := Image.create(128, 128, false, Image.FORMAT_RGB8)
	img.fill(skin)
	var eye := Color(0.04, 0.04, 0.06)
	for y in range(50, 62):
		for x in range(38, 52): img.set_pixel(x, y, eye)   # left eye
		for x in range(76, 90): img.set_pixel(x, y, eye)  # right eye
	for x in range(46, 82): img.set_pixel(x, 88, Color(0.32, 0.12, 0.12))  # mouth
	return ImageTexture.create_from_image(img)
```

### 5.12 Performance (Android must stay playable)
<= 8 shadow-casting dynamic lights near the player (distant rooms shadowless);
textures <= 512 px; reuse materials; MultiMesh for repeated props (books,
crates); fog/volumetric/SSAO off on Android quality setting; map generation
deterministic from seed (server sends seed + layout, clients rebuild locally);
bake NavigationRegion3D in code after generation.

## 6. GAMEPLAY (condensed)
- Loop: EXPLORE -> INVESTIGATE -> IDENTIFY -> OBJECTIVES -> ACTIVATE
  EXTRACTION -> SURVIVE 60-90 s loud countdown -> ESCAPE.
- >= 3 entities, mechanically different: Wraith (cold + EMF), Poltergeist
  (object manipulation + noise), Mimic (fake evidence/sounds). Each has 2-3
  distinctive evidence types + a weakness.
- Entity powers (with cooldowns/costs): slam doors; flicker/kill lights;
  move/throw props; fake footsteps/whispers at a chosen spot; brief
  manifestation; corrupt an area; attack isolated high-fear targets.
- Counterplay: flashlight suppresses nearby powers; salt lines block entity
  movement; camera flash reveals manifestations; cleansing ritual weakens
  the entity; sprint/hide with stamina.
- Fear 0-100 (darkness, isolation, entity activity): heartbeat/breathing
  audio, camera sway, false sounds, slower interactions. Never nauseating.
- Objectives per match: restore power, find key/fuse, locate cursed object,
  activate comms. Extraction unlocks only after objectives.
- Bots reuse the player systems: investigator bots navigate, complete
  objectives, extract; entity bot uses powers on cooldown and targets
  isolated players.
